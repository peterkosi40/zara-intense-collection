# Deployment

1. Upload every file in this folder to the root of a new GitHub repository (not this folder itself).
2. Connect the repository to Cloudflare Pages.
3. Framework preset: `None`.
4. Build command: `exit 0`.
5. Build output directory: `.`.
6. Production branch: select the branch that exists in GitHub, usually `main`.
7. Deploy, then open the assigned `pages.dev` address and test the menu, filters, cart and images.

Keep all JPEG files alongside `index.html`; do not upload only the HTML/CSS/JS files.
