# ZARA INTENSE COLLECTION — E-commerce Demo

A responsive premium fashion storefront concept featuring product category filters, search, sort, wishlist feedback, a shopping bag drawer, newsletter interaction, and a profile preview modal.

## Files
- `index.html` — page structure and product content
- `styles.css` — responsive styles and visual system
- `script.js` — front-end interactions
- `campaign-editorial.jpg` and six product JPEGs — locally stored generated images
- `brand-mark.svg` — favicon

## Preview
Open `index.html` in a browser. Product images are stored alongside the HTML, with no separate image directory. Google Fonts are optional; the site has local fallback fonts.

## Demo limitations
This is a front-end portfolio demonstration. The cart is session-only; there is no payment processing, inventory, order submission, authentication, customer database, or persistent newsletter service. Product prices and content are illustrative. Connect a backend and payment provider before production use.
